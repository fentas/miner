BTC Miner

High-performance Bitcoin miner in C++17

Features

SHA-NI & SIMD

Hardware SHA-256 acceleration with AVX2/AVX512 multi-hashing

GPU Mining

CUDA for NVIDIA, OpenCL for AMD/Intel GPUs

Stratum V1 & V2

JSON and binary protocols with auto-reconnect

Web Dashboard

Real-time stats, charts, and controls via WebSocket

Performance

SHA-NI~800 MH/s
AVX512 (16-way)~450 MH/s
AVX2 (8-way)~250 MH/s
GPU100-1000+ MH/s

Quick Start

git clone https://github.com/fentas/miner
cd miner && mkdir build && cd build
cmake .. -DNATIVE_BUILD=ON && make -j$(nproc)
cp ../btcminer.conf.example btcminer.conf
./btcminer
